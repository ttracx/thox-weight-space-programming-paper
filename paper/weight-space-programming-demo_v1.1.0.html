4. What the authors' own files show

THOX re-analysed the authors' released per-problem MATH-500 records (A0, 4 samples per problem, thinking on).

A gain on hundreds of problems and a loss on none is what removing one uniform obstacle looks like. A decoding change that avoids the same obstacle would leave the same signature, which is why section 6 matters.

5. Ship: size an exact signed patch

An exact rank-1 patch ships, per tensor, the direction u (float32), the edited column indices and alpha, plus a sparse residual for entries the factor alone misses by one rounding step: |P| = Σ (4d + 2|C| + 8) + 6r. Defaults are the measured Experiment 8 values (two tensors; totals for changed and residual entries).

RepresentationBytesExact

The loader verifies an Ed25519 signature, the base tensors' SHA-256, applies to the inactive A/B slot, checks every result hash and only then switches. A factor without its residual fails that check by design.

6. The control: loop detector and decision rule

The test: some run of 300 consecutive word 8-grams in which at least 270 already appeared earlier. It is causal, so the onset is where a streaming interrupt would rewind to.

Pre-registered decision rule (Section 5.2): paired MATH-500 difference, released edit with thinking on minus the unedited base with thinking off, and its 95% interval, in points.
